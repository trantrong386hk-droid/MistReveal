## 双层防护机制详解

### 第一层防护：LLM输入层强制约束

```
┌──────────────────────────────────────────────────────┐
│                  第一层防护（方案A）                   │
│              TextGenerationService.swift              │
├──────────────────────────────────────────────────────┤
│                                                       │
│  目标：在LLM生成前强制约束输入                         │

│  实现方式：                                           │
│  1️⃣ 明确核心约束：伴侣五行 = 喜用神                   │
│     "【核心约束】伴侣五行 = 喜用神'木'"                │
│                                                       │
│  2️⃣ 直接嵌入调色盘具体文字                            │
│     - 肤色：肌肤自然健康，白里透红                     │
│     - 服饰：松绿色棉麻衬衫                            │
│     - 光影：林间光影                                  │
│     - 环境：葱茏绿意                                  │
│                                                       │
│  3️⃣ 明确禁止词汇                                      │
```

```
用户输入
  ↓
八字计算（喜用神=木）
  ↓
LLM生成（系统提示词）
  ├─ 相生规则："金生水" ❌
  ├─ LLM选择：金命伴侣 ❌
  └─ 生成特质：冷色调 ❌
  ↓

  ↓

```

### 修复后：双层防护（LLM + 代码兜底）

```
用户输入
  ↓
八字计算（喜用神=木）
  ↓
【第一层】强化LLM规则
  ├─ 明确：伴侣五行 = 喜用神
  ├─ 嵌入：调色盘具体文字
  └─ 禁止：其他五行特质

  ↓

  ↓
生成图像：温暖色调 ✅

优势：即使LLM忽略规则，代码也能修正
```

### ImageGenerationService.swift（第二层防护）

```swift
// Line 298-337
// 🔥 === 强制清理冷色调词汇（兜底保护）===
var cleanedPrompt = prompt
if let bazi = baziInfo, (bazi.xiYongShen == "木" || bazi.xiYongShen == "火") {
    // 定义冷色调 → 暖色调映射表
    let coldToWarmMapping: [String: String] = [
        "白皙透亮": "肌肤自然健康，白里透红",
        "冷锻银器": "温润如玉",
        "银灰": "松绿色",
        // ... 更多映射
    ]

    var didReplace = false
    for (cold, warm) in coldToWarmMapping {
        if cleanedPrompt.contains(cold) {
            cleanedPrompt = cleanedPrompt.replacingOccurrences(
                of: cold, with: warm
            )
            didReplace = true
        }
    }

    if didReplace {
        print("🔥 [ImageGen] 强制清理冷色调词汇 → 替换为暖色调")
        print("   原始: \(prompt.prefix(100))...")
        print("   清理后: \(cleanedPrompt.prefix(100))...")
    }
}
```

## 总结

双层防护机制确保：
1. ✅ **第一层（70-80%）：** LLM如果遵守规则 → 直接生成正确结果
2. ✅ **第二层（100%）：** LLM如果忽略规则 → 后置修复保护
3. ✅ **综合效果：** 无论LLM是否遵守规则，最终都能生成正确的温暖木系特质

修复风险：低（只在木/火场景触发，不影响其他流程）
